YAAKSHITAA PORTFOLIO WEBSITE

FILES
- index.html: all portfolio content and sections
- style.css: responsive, refined editorial blush/burgundy theme
- script.js: mobile navigation
- resume.pdf: one-page resume
- student-management-system.py: downloadable project source file
- assets/: SafeLab Sentinel, carbon-composite research, and student tracker images

OPEN LOCALLY
1. Extract the ZIP.
2. Open index.html in Chrome or Edge.
3. For editing, open the folder in VS Code and use the Live Server extension.

PUBLISH WITH GITHUB PAGES
IMPORTANT: Upload the CONTENTS of this folder into the ROOT of your GitHub repository. The index.html file must be visible on the repository's main Code page without opening another folder.
Upload index.html, style.css, script.js, resume.pdf, student-management-system.py, and the assets folder together.
Then open Settings > Pages, select Deploy from a branch, choose main and /(root), and click Save.

BEFORE SHARING
- Replace “add your professional email” in the resume and website with your real email.
- Add GitHub, LinkedIn, and any public project links.
- Check that all project descriptions match your actual contributions.
- The writing section is intentionally marked as a placeholder until you have a real writing sample.
- Review student-management-system.py for hardcoded credentials before publishing it publicly.
